1. アプリケーション概要 (About)

Personal Workspace Assistant は、個人ユーザー（開発者本人）のタスク管理、予定管理、およびメモ整理を自動化・効率化するために開発された専用アシスタントツールです。

本ツールは、ユーザー本人の明示的な操作に基づいてGoogle Workspaceの各種サービス（Google Tasks, Google Calendar, Google Drive等）と安全に通信し、日々の作業支援を行います。

2. プライバシーポリシー (Privacy Policy)

本アプリケーションは、利用者のプライバシーと個人情報の保護を極めて重要視しています。

データの収集と利用目的

本ツールは、Google OAuth 2.0 認証を通じて以下の機能を提供するためにのみ Google API にアクセスします：

  • Google Tasks API: ユーザーが依頼したタスクの追加・一覧取得・完了状態の更新。
  • Google Calendar API: カレンダー上のスケジュールの確認および予定の追加。
  • Google Drive / Sheets / Gmail API: ユーザーの指定に基づくメモやスプレッドシートへの記録および確認。

データの保管と第三者提供の禁止

認証情報（OAuthトークン）および取得されたデータは、利用者のローカルPC環境内にのみ安全に保存されます。

  • 取得されたデータが開発者を含むいかなる第三者の外部サーバーに送信されることは一切ありません。
  • ユーザーデータを販売、広告目的で利用、または他のサービスへ再配布することは一切行いません。

Google API ユーザーデータに関する開示

本アプリケーションにおける Google API から受け取った情報の使用および他のアプリへの転送は、制限付き使用（Limited Use）要件を含む Google API Services User Data Policy に完全に準拠しています。
